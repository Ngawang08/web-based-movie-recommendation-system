# Movie Recommendation System

This is a web-based movie recommendation system developed using Flask, MySQL, and HTML with Jinja templates.

## Features
- User registration and login
- Movie browsing and search
- Rating system (add, update, delete)
- Personalized recommendations
- Watchlist functionality
- Admin panel

## Technologies Used
- Python (Flask)
- MySQL
- HTML, CSS, Jinja

## Note
All HTML files should be placed inside a 'templates' folder for proper execution.
